Incipits musicaux exportés de Finale (PNG).

Convention : incipits/<identifiant-de-la-notice>/<n>.png
  - <identifiant> = champ `id` du fichier data/works/<id>.yaml (permanent, indépendant du numéro Th)
  - <n> = numéro d'ordre du mouvement dans la notice, à partir de 1

Exemple : incipits/wiener-konzert/3.png  ->  3e Lied de Wiener Konzert.
Le générateur détecte les fichiers présents ; les autres apparaissent comme « Incipit à venir ».
Conseil d'export : largeur fixe (p. ex. 1600 px), fond transparent ou blanc, 300 dpi.
